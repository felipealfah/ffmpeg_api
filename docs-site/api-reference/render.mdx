# POST /api/render

Cria um job de renderização de vídeo assíncrono baseado na timeline fornecida.

## Endpoint

```
POST http://localhost:3000/api/render
```

## Exemplo Rápido

Quer testar rapidamente? Copie e cole este comando no terminal:

```bash
curl -X POST "http://localhost:3000/api/render" \
  -H "Content-Type: application/json" \
  -d '{
    "timeline": {
      "tracks": [{
        "clips": [{
          "asset": {
            "type": "video",
            "source": "url",
            "src": "https://sample-videos.com/zip/10/mp4/SampleVideo_1280x720_1mb.mp4"
          },
          "start": 0,
          "length": 5
        }]
      }]
    },
    "output": {
      "format": "mp4",
      "resolution": "1280x720",
      "quality": "medium"
    }
  }'
```

**O que este exemplo faz:**
- 📥 Baixa um vídeo de exemplo da internet
- ✂️ Corta os primeiros 5 segundos
- 🎬 Renderiza um novo vídeo MP4 em 720p
- ⚡ Retorna um `jobId` para acompanhar o progresso

**Resposta esperada:**
```json
{
  "jobId": "123e4567-e89b-12d3-a456-426614174000",
  "status": "queued",
  "message": "Job criado com sucesso"
}
```

Use o `jobId` para verificar o status: `GET /api/media/job/{jobId}/status`

## Parâmetros

### timeline (obrigatório)

Estrutura que define a composição do vídeo.

<AccordionGroup>
  <Accordion title="tracks" icon="layers">
    Array de tracks (trilhas) que compõem o vídeo.
    
    ```json
    {
      "tracks": [
        {
          "clips": [/* array de clips */]
        }
      ]
    }
    ```
    
    - **Tipo**: `Array<Track>`
    - **Obrigatório**: ✅
    - **Mínimo**: 1 track
  </Accordion>
  
  <Accordion title="clips" icon="scissors">
    Array de clips dentro de cada track.
    
    ```json
    {
      "clips": [
        {
          "asset": {/* definição do asset */},
          "start": 0,
          "length": 10
        }
      ]
    }
    ```
    
    - **Tipo**: `Array<Clip>`
    - **Obrigatório**: ✅
    - **Mínimo**: 1 clip por track
  </Accordion>
  
  <Accordion title="asset" icon="file">
    Definição do recurso (vídeo, áudio, imagem, texto).
    
    ```json
    {
      "asset": {
        "type": "video",
        "source": "url",
        "src": "https://exemplo.com/video.mp4",
        "volume": 0.8,
        "isBackground": false
      }
    }
    ```
    
    **Propriedades:**
    - `type`: "video", "audio", "image", "text"
    - `source`: "url", "local", "upload"
    - `src`: URL ou caminho do arquivo
    - `volume`: 0.0 a 1.0 (apenas áudio)
    - `isBackground`: boolean (apenas áudio)
  </Accordion>
</AccordionGroup>

Configurações de saída do vídeo.

<Tabs>

## Response

### Sucesso (200)

```json
{
  "jobId": "123e4567-e89b-12d3-a456-426614174000",
  "status": "queued",
  "message": "Job criado com sucesso",
  "estimatedTime": "~30 segundos",
  "queuePosition": 2,
  "timeline": {
    "totalDuration": 23.5,
    "tracksCount": 2,
    "clipsCount": 5
  }
}
```

**Campos:**
- `jobId`: ID único do job (UUID)
- `status`: Status inicial ("queued")
- `message`: Mensagem de confirmação
- `estimatedTime`: Tempo estimado para conclusão
- `queuePosition`: Posição na fila de processamento
- `timeline`: Informações sobre a timeline processada

### Erro (400)

```json
{
  "error": {
    "code": "INVALID_TIMELINE",
    "message": "Timeline structure is invalid",
    "details": [
      {
        "field": "timeline.tracks",
        "message": "At least one track is required"
      }
    ]
  }
}
```

### Erro (413)

```json
{
  "error": {
    "code": "PAYLOAD_TOO_LARGE",
    "message": "Request payload exceeds maximum size",
    "details": "Maximum size: 10MB"
  }
}
```

## Códigos de Erro

| Código | Descrição | Solução |
|--------|-----------|---------|
| `INVALID_TIMELINE` | Estrutura da timeline inválida | Verificar estrutura JSON |
| `ASSET_NOT_FOUND` | Asset não pode ser carregado | Verificar URL e permissões |
| `INVALID_OUTPUT` | Configuração de saída inválida | Verificar formato e resolução |
| `QUEUE_FULL` | Fila de processamento cheia | Tentar novamente mais tarde |
| `RATE_LIMIT` | Limite de requisições excedido | Aguardar antes de nova tentativa |

## Limites

<CardGroup cols={2}>
  <Card title="📏 Tamanho" icon="ruler">
    - **Payload**: 10MB máximo
    - **Assets**: 100MB por arquivo
    - **Duração**: 10 minutos máximo
  </Card>
  <Card title="⏱️ Performance" icon="clock">
    - **Timeout**: 600s máximo
    - **Jobs simultâneos**: 3 por usuário
    - **Jobs por hora**: 50 por usuário
  </Card>
</CardGroup>

<Warning>
  **Importante**: Assets devem estar publicamente acessíveis. URLs privadas ou que requerem autenticação não são suportadas.
</Warning>

<Tip>
  **Dica**: Use o endpoint `/api/media/info` para descobrir a duração dos seus assets antes de criar a timeline.
</Tip>
