# GET /api/media/info

Retorna informações detalhadas sobre um arquivo de mídia, incluindo duração, resolução, fps e formato. Útil para saber a duração antes de criar clips.

## Endpoint

```
GET http://localhost:3000/api/media/info
```

## Parâmetros

### Query Parameters

| Parâmetro | Tipo | Descrição |
|-----------|------|-----------|
| `url` | string (URL) | URL do arquivo de mídia |

## Campos da Resposta

### Campos Comuns

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `type` | string | Tipo de mídia: "video", "audio", "image" |
| `format` | string | Formato do arquivo (mp4, mp3, jpeg, etc.) |
| `size` | number | Tamanho do arquivo em bytes |
| `hasAudio` | boolean | Se o arquivo contém áudio |
| `hasVideo` | boolean | Se o arquivo contém vídeo |
| `metadata` | object | Metadados do arquivo |
| `streams` | array | Informações dos streams |

### Campos de Vídeo

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `duration` | number | Duração em segundos |
| `width` | number | Largura em pixels |
| `height` | number | Altura em pixels |
| `fps` | number | Frames por segundo |
| `bitrate` | number | Taxa de bits total |

### Campos de Áudio

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `duration` | number | Duração em segundos |
| `bitrate` | number | Taxa de bits do áudio |
| `sampleRate` | number | Taxa de amostragem |
| `channels` | number | Número de canais |

### Campos de Imagem

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `width` | number | Largura em pixels |
| `height` | number | Altura em pixels |

```javascript JavaScript
async function obterInfoMidia(url) {
  try {
    const response = await fetch(`/api/media/info?url=${encodeURIComponent(url)}`);
    
    if (!response.ok) {
      const error = await response.json();
      throw new Error(error.error.message);
    }
    
    const info = await response.json();
    
    console.log(`📁 Tipo: ${info.type}`);
    console.log(`📏 Formato: ${info.format}`);
    console.log(`💾 Tamanho: ${(info.size / 1024 / 1024).toFixed(2)}MB`);
    
    if (info.duration) {

    }
    
    if (info.width && info.height) {
      console.log(`📐 Resolução: ${info.width}x${info.height}`);
    }
    
    return info;
  } catch (error) {
    console.error('❌ Erro ao obter informações:', error.message);
    throw error;
  }
}
```

```python Python
import requests
from urllib.parse import urlencode

def obter_info_midia(url):
    """Obtém informações de um arquivo de mídia"""
    params = {'url': url}
    response = requests.get(f"/api/media/info?{urlencode(params)}")
    
    if response.status_code != 200:
        error = response.json()
        raise Exception(error['error']['message'])
    
    info = response.json()
    
    print(f"📁 Tipo: {info['type']}")
    print(f"📏 Formato: {info['format']}")
    print(f"💾 Tamanho: {info['size'] / 1024 / 1024:.2f}MB")
    
    if 'duration' in info:
        print(f"⏱️ Duração: {info['duration']}s")
    
    if 'width' in info and 'height' in info:
        print(f"📐 Resolução: {info['width']}x{info['height']}")
    
    return info

# Exemplo de uso
try:
    info = obter_info_midia('https://exemplo.com/video.mp4')
    print("Informações obtidas:", info)
except Exception as error:
    print("Erro:", error)
```

## Casos de Uso

### 1. Validar Assets Antes de Usar

```javascript
async function validarAssets(assets) {
  const validados = [];
  
  for (const asset of assets) {
    try {
      const info = await obterInfoMidia(asset.src);
      
      validados.push({
        ...asset,
        duration: info.duration,
        width: info.width,
        height: info.height,
        valid: true
      });
    } catch (error) {
      validados.push({
        ...asset,
        valid: false,
        error: error.message
      });
    }
  }
  
  return validados;
}
```

### 2. Calcular Duração Total da Timeline

```javascript
async function calcularDuracaoTimeline(timeline) {
  let duracaoTotal = 0;
  
  for (const track of timeline.tracks) {
    for (const clip of track.clips) {
      if (clip.length === 'auto') {
        // Obter duração real do asset
        const info = await obterInfoMidia(clip.asset.src);
        const duracaoDisponivel = info.duration - clip.start;
        duracaoTotal = Math.max(duracaoTotal, clip.start + duracaoDisponivel);
      } else {
        duracaoTotal = Math.max(duracaoTotal, clip.start + clip.length);
      }
    }
  }
  
  return duracaoTotal;
}
```

### 3. Otimizar Qualidade Baseada no Asset

```javascript
async function otimizarQualidade(assetUrl) {
  const info = await obterInfoMidia(assetUrl);
  
  // Determinar qualidade baseada na resolução original
  if (info.width >= 3840) {
    return { quality: 'high', resolution: '3840x2160' };
  } else if (info.width >= 1920) {
    return { quality: 'high', resolution: '1920x1080' };
  } else {
    return { quality: 'medium', resolution: '1280x720' };
  }
}
```

### 4. Verificar Compatibilidade

```javascript
async function verificarCompatibilidade(assetUrl) {
  const info = await obterInfoMidia(assetUrl);
  
  const formatosSuportados = ['mp4', 'mov', 'webm', 'mp3', 'wav', 'jpeg', 'png'];
  
  if (!formatosSuportados.includes(info.format)) {
    throw new Error(`Formato ${info.format} não suportado`);
  }
  
  if (info.size > 100 * 1024 * 1024) { // 100MB
    throw new Error('Arquivo muito grande (máximo 100MB)');
  }
  
  return true;
}
```

## Formatos Suportados

### Vídeo
- **MP4** (H.264, H.265)
- **MOV** (QuickTime)
- **WebM** (VP8, VP9)
- **AVI** (limitado)

### Áudio
- **MP3**
- **WAV**
- **AAC**
- **OGG**

### Imagem
- **JPEG**
- **PNG**
- **GIF**
- **WebP**
