# Slideshow com Transições

Aprenda a criar slideshows profissionais combinando múltiplas imagens, transições suaves e sincronização musical perfeita.

## Resultado Final

Este exemplo criará um slideshow com:
- ✅ Múltiplas imagens em sequência
- ✅ Transições suaves entre slides
- ✅ Música de fundo sincronizada
- ✅ Texto informativo customizável
- ✅ Timing automático ou manual

async function criarSlideshow() {
  const images = [
    'https://images.unsplash.com/photo-1506905925346-21bda4d32df4?w=1920&h=1080&fit=crop&auto=format&q=80',
    'https://images.unsplash.com/photo-1469474968028-56623f02e42e?w=1920&h=1080&fit=crop&auto=format&q=80',
    'https://images.unsplash.com/photo-1441974231531-c6227db76b6e?w=1920&h=1080&fit=crop&auto=format&q=80',
    'https://images.unsplash.com/photo-1518837695005-2083093ee35b?w=1920&h=1080&fit=crop&auto=format&q=80',
    'https://images.unsplash.com/photo-1470071459604-3b5ec3a7fe05?w=1920&h=1080&fit=crop&auto=format&q=80'
  ];
  
  const titles = [
    '🏔️ MONTANHAS MAJESTOSAS',
    '🌊 OCEANOS INFINITOS',
    '🌲 FLORESTAS EXUBERANTES',
    '🏜️ DESERTOS MÍSTICOS',
    '🌅 HORIZONTES INFINITOS'
  ];
  
  const slideLength = 6; // segundos por slide
  
  // Gerar clips de imagem
  const imageClips = images.map((src, index) => ({
    asset: {
      type: 'image',
      source: 'url',
      src: src
    },
    start: index * slideLength,
    length: slideLength
  }));
  
  // Gerar clips de texto
  const textClips = titles.map((title, index) => ({
    asset: {
      type: 'text',
      text: title,
      style: {
        fontSize: 56,
        fontColor: 'white',
        outlineColor: 'black',
        outline: 4,
        bold: true,
        alignment: 'center',
        position: 'top',
        marginV: 100
      }
    },
    start: index * slideLength,
    length: slideLength
  }));
  
  const response = await fetch('http://localhost:3000/api/media/render', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      timeline: {
        tracks: [
          // Track de imagens
          { clips: imageClips },
          // Track de títulos
          { clips: textClips },
          // Track de áudio
          {
            clips: [
              {
                asset: {
                  type: 'audio',
                  source: 'url',
                  src: 'https://www.soundhelix.com/examples/mp3/SoundHelix-Song-4.mp3',
                  isBackground: true,
                  volume: 0.65
                },
                start: 0,
                length: 'auto'
              }
            ]
          }
        ]
      },
      output: {
        format: 'mp4',
        resolution: '1920x1080',
        quality: 'high',
        fps: 30,
        bitrate: '10000k'
      }
    })
  });

  const job = await response.json();
  console.log('Slideshow criado:', job.jobId);
  return job.jobId;
}

import requests

def criar_slideshow():
    images = [
        'https://images.unsplash.com/photo-1506905925346-21bda4d32df4?w=1920&h=1080&fit=crop&auto=format&q=80',
        'https://images.unsplash.com/photo-1469474968028-56623f02e42e?w=1920&h=1080&fit=crop&auto=format&q=80',
        'https://images.unsplash.com/photo-1441974231531-c6227db76b6e?w=1920&h=1080&fit=crop&auto=format&q=80',
        'https://images.unsplash.com/photo-1518837695005-2083093ee35b?w=1920&h=1080&fit=crop&auto=format&q=80',
        'https://images.unsplash.com/photo-1470071459604-3b5ec3a7fe05?w=1920&h=1080&fit=crop&auto=format&q=80'
    ]
    
    titles = [
        '🏔️ MONTANHAS MAJESTOSAS',
        '🌊 OCEANOS INFINITOS',
        '🌲 FLORESTAS EXUBERANTES',
        '🏜️ DESERTOS MÍSTICOS',
        '🌅 HORIZONTES INFINITOS'
    ]
    
    slide_length = 6  # segundos por slide
    
    # Gerar clips de imagem
    image_clips = []
    for i, src in enumerate(images):
        image_clips.append({
            "asset": {
                "type": "image",
                "source": "url",
                "src": src
            },
            "start": i * slide_length,
            "length": slide_length
        })
    
    # Gerar clips de texto
    text_clips = []
    for i, title in enumerate(titles):
        text_clips.append({
            "asset": {
                "type": "text",
                "text": title,
                "style": {
                    "fontSize": 56,
                    "fontColor": "white",
                    "outlineColor": "black",
                    "outline": 4,
                    "bold": True,
                    "alignment": "center",
                    "position": "top",
                    "marginV": 100
                }
            },
            "start": i * slide_length,
            "length": slide_length
        })
    
    payload = {
        "timeline": {
            "tracks": [
                {"clips": image_clips},
                {"clips": text_clips},
                {
                    "clips": [
                        {
                            "asset": {
                                "type": "audio",
                                "source": "url",
                                "src": "https://www.soundhelix.com/examples/mp3/SoundHelix-Song-4.mp3",
                                "isBackground": True,
                                "volume": 0.65
                            },
                            "start": 0,
                            "length": "auto"
                        }
                    ]
                }
            ]
        },
        "output": {
            "format": "mp4",
            "resolution": "1920x1080",
            "quality": "high",
            "fps": 30,
            "bitrate": "10000k"
        }
    }
    
    response = requests.post("http://localhost:3000/api/media/render", json=payload)
    return response.json()

## Passo a Passo

### 1. Planejamento do Slideshow

<Steps>
  <Step title="Definir Estrutura">
    Planeje a sequência e timing dos slides
    
    ```json
    {
      "structure": {
        "totalSlides": 5,
        "slideLength": 6,
        "transitionTime": 0.5,
        "totalDuration": 30
      }
    }
    ```
  </Step>
  
  <Step title="Preparar Assets">
    Organize as imagens e conteúdo textual
    
    ```json
    {
      "assets": {
        "images": [
          "slide1.jpg",
          "slide2.jpg",
          "slide3.jpg"
        ],
        "texts": [
          "Título 1",
          "Título 2", 
          "Título 3"
        ]
      }
    }
    ```
  </Step>
  
  <Step title="Configurar Timeline">
    Defina timing preciso para cada elemento
    
    ```json
    {
      "timeline": {
        "slide1": { "start": 0, "length": 6 },
        "slide2": { "start": 6, "length": 6 },
        "slide3": { "start": 12, "length": 6 }
      }
    }
    ```
  </Step>
  
  <Step title="Adicionar Áudio">
    Configure música de fundo sincronizada
    
    ```json
    {
      "audio": {
        "src": "background_music.mp3",
        "volume": 0.6,
        "loop": true
      }
    }
    ```
  </Step>
</Steps>

## Automatização e Scripts

### 🔧 Gerador Automático

```javascript
function gerarSlideshowAutomatico(config) {
  const {
    images,
    titles,
    slideLength = 5,
    transitionTime = 0.5,
    audioSrc,
    audioVolume = 0.6
  } = config;
  
  const imageClips = images.map((src, index) => ({
    asset: { type: 'image', source: 'url', src },
    start: index * slideLength,
    length: slideLength
  }));
  
  const textClips = titles.map((title, index) => ({
    asset: {
      type: 'text',
      text: title,
      style: {
        fontSize: 48,
        fontColor: 'white',
        outlineColor: 'black',
        outline: 3,
        bold: true,
        alignment: 'center',
        position: 'top',
        marginV: 100
      }
    },
    start: index * slideLength,
    length: slideLength
  }));
  
  return {
    timeline: {
      tracks: [
        { clips: imageClips },
        { clips: textClips },
        {
          clips: [{
            asset: {
              type: 'audio',
              source: 'url',
              src: audioSrc,
              isBackground: true,
              volume: audioVolume
            },
            start: 0,
            length: 'auto'
          }]
        }
      ]
    },
    output: {
      format: 'mp4',
      resolution: '1920x1080',
      quality: 'high',
      fps: 30,
      bitrate: '8000k'
    }
  };
}
```
