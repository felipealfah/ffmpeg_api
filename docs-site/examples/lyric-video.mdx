# Lyric Video

Aprenda a criar vídeos com letras de música combinando áudio, texto e imagens de fundo.

## Resultado Final

Este exemplo criará um vídeo com:
- ✅ Música de fundo
- ✅ Texto animado com as letras
- ✅ Imagem de fundo estática
- ✅ Duração automática baseada no áudio

## Personalizações Avançadas

### 1. Múltiplas Linhas de Texto

Para criar diferentes textos em momentos específicos:

```json
{
  "clips": [
    {
      "asset": {
        "type": "text",
        "text": "🎵 Primeira estrofe 🎵",
        "style": {
          "fontSize": 52,
          "fontColor": "#FFD700",
          "bold": true,
          "alignment": "center"
        }
      },
      "start": 0,
      "length": 10
    },
    {
      "asset": {
        "type": "text",
        "text": "🎶 Segunda estrofe 🎶",
        "style": {
          "fontSize": 52,
          "fontColor": "#FF6B35",
          "bold": true,
          "alignment": "center"
        }
      },
      "start": 10,
      "length": 10
    }
  ]
}
```

## Dicas Importantes

<Tip>
  **Duração Automática**: Use `length: "auto"` no áudio para que o vídeo tenha exatamente a duração da música.
</Tip>

<Warning>
  **Sincronização**: Certifique-se de que o texto apareça nos momentos corretos ajustando os valores de `start` e `length`.
</Warning>

<Note>
  **Qualidade**: Para lyric videos, recomendamos usar `quality: "high"` e `bitrate: "4000k"` para melhor qualidade de texto.
</Note>
