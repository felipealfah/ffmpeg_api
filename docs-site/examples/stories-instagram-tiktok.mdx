# Stories Instagram/TikTok

Aprenda a criar vídeos verticais otimizados para Instagram Stories, TikTok e outras redes sociais com formato 9:16.

## Resultado Final

Este exemplo criará um vídeo com:
- ✅ Formato vertical 9:16 (1080x1920)
- ✅ Múltiplos clips curtos com transições
- ✅ Texto animado sobreposto
- ✅ Áudio de fundo automático
- ✅ Duração otimizada (15-30 segundos)

## Dicas de Otimização

### 📱 Design Vertical

<AccordionGroup>
  <Accordion title="Posicionamento de Texto" icon="text">
    ```json
    {
      "style": {
        "position": "top",    // ou "bottom"
        "marginV": 100,       // margem do topo/fundo
        "alignment": "center", // alinhamento horizontal
        "fontSize": 64        // tamanho otimizado para mobile
      }
    }
    ```
    
    - Use margens grandes (100-200px) para evitar sobreposição
    - Posicione textos importantes no terço superior ou inferior
    - Evite o centro vertical onde ficam os botões
  </Accordion>
  
  <Accordion title="Cores e Contraste" icon="palette">
    ```json
    {
      "style": {
        "fontColor": "white",
        "outlineColor": "black",
        "outline": 3,
        "bold": true
      }
    }
    ```
    
    - Sempre use outline para garantir legibilidade
    - Prefira cores claras com outline escuro
    - Teste em diferentes fundos de vídeo
  </Accordion>
  
  <Accordion title="Timing e Transições" icon="clock">
    ```json
    {
      "clips": [
        { "start": 0, "length": 3 },   // Intro rápida
        { "start": 3, "length": 7 },   // Conteúdo principal
        { "start": 10, "length": 3 },  // Transição
        { "start": 13, "length": 7 }   // Final
      ]
    }
    ```
    
    - Mantenha clips curtos (3-7 segundos)
    - Use transições rápidas (2-3 segundos)
    - Sincronize com batidas da música
  </Accordion>
</AccordionGroup>

### 🎵 Áudio Otimizado

<AccordionGroup>
  <Accordion title="Volume Balanceado" icon="volume">
    ```json
    {
      "asset": {
        "type": "audio",
        "isBackground": true,
        "volume": 0.6  // 60% para não sobrepor narração
      }
    }
    ```
    
    - Stories: 0.5-0.7 (muitos assistem sem som)
    - TikTok: 0.7-0.9 (áudio é crucial)
    - YouTube Shorts: 0.8-1.0 (qualidade máxima)
  </Accordion>
  
  <Accordion title="Música Trending" icon="music">
    Use músicas populares nas plataformas:
    
    - **Instagram**: Biblioteca de música do Instagram
    - **TikTok**: Sounds trending
    - **YouTube**: Música livre de direitos autorais
    
    ```json
    {
      "asset": {
        "type": "audio",
        "src": "https://www.soundhelix.com/examples/mp3/SoundHelix-Song-2.mp3",
        "isBackground": true,
        "volume": 0.75
      }
    }
    ```
  </Accordion>
</AccordionGroup>

### ⚡ Performance

<AccordionGroup>
  <Accordion title="Bitrate Otimizado" icon="gauge">
    ```json
    {
      "output": {
        "bitrate": "5000k",  // Instagram Stories
    ```

    - 30fps é suficiente para a maioria dos casos
    - 60fps apenas para slow-motion ou gaming
    - Formato MP4 é universal
  </Accordion>

## Troubleshooting

### ❌ Problemas Comuns

<AccordionGroup>
  <Accordion title="Texto Não Aparece" icon="eye-slash">
    **Problema**: Texto não é visível no vídeo
    
    **Soluções**:
    ```json
    {
      "style": {
        "fontSize": 48,        // Aumente o tamanho
        "fontColor": "white",  // Use cor contrastante
        "outlineColor": "black", // Adicione outline
        "outline": 3,          // Outline grosso
        "bold": true           // Texto em negrito
      }
    }
    ```
  </Accordion>
  
  <Accordion title="Áudio Muito Alto/Baixo" icon="volume-x">
    **Problema**: Volume inadequado do áudio
    
    **Soluções**:
    ```json
    {
      "asset": {
        "type": "audio",
        "isBackground": true,
        "volume": 0.6  // Ajuste entre 0.1 e 1.0
      }
    }
    ```
    
    - Stories: 0.5-0.7
    - TikTok: 0.7-0.9
    - YouTube: 0.8-1.0
  </Accordion>
  
  <Accordion title="Vídeo Muito Pesado" icon="weight">
    **Problema**: Arquivo muito grande para upload
    
    **Soluções**:
    ```json
    {
      "output": {
        "quality": "medium",   // Reduza a qualidade
        "bitrate": "3000k",    // Reduza o bitrate
        "fps": 30             // Use 30fps em vez de 60
      }
    }
    ```
  </Accordion>
</AccordionGroup>
