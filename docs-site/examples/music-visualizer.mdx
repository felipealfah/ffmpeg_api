# Visualizador de Música

Aprenda a criar visualizações de áudio impressionantes combinando música, elementos visuais animados e efeitos sincronizados.

## Resultado Final

Este exemplo criará um vídeo com:
- ✅ Música como elemento principal
- ✅ Background dinâmico e animado
- ✅ Texto com informações da música
- ✅ Elementos visuais sincronizados
- ✅ Múltiplos formatos de saída

## Passo a Passo

### 1. Estrutura por Camadas

<Steps>
  <Step title="Background Dinâmico">
    Configure backgrounds que mudam conforme a música
    
    ```json
    {
      "clips": [
        {
          "asset": {
            "type": "image",
            "src": "background_intro.jpg"
          },
          "start": 0,
          "length": 30
        },
        {
          "asset": {
            "type": "image",
            "src": "background_drop.jpg"
          },
          "start": 30,
          "length": 30
        }
      ]
    }
    ```
  </Step>
  
  <Step title="Capa do Álbum">
    Adicione a arte do álbum como elemento central
    
    ```json
    {
      "clips": [
        {
          "asset": {
            "type": "image",
            "src": "album_cover.jpg"
          },
          "start": 0,
          "length": "auto"
        }
      ]
    }
    ```
  </Step>
  
  <Step title="Texto Sincronizado">
    Textos que mudam conforme as seções da música
    
    ```json
    {
      "clips": [
        {
          "asset": {
            "type": "text",
            "text": "🎵 INTRO 🎵",
            "style": { "fontSize": 48, "fontColor": "white" }
          },
          "start": 0,
          "length": 15
        },
        {
          "asset": {
            "type": "text",
            "text": "🔥 DROP 🔥",
            "style": { "fontSize": 64, "fontColor": "yellow" }
          },
          "start": 30,
          "length": 10
        }
      ]
    }
    ```
  </Step>
  
  <Step title="Áudio Principal">
    Configure o áudio com volume otimizado
    
    ```json
    {
      "clips": [
        {
          "asset": {
            "type": "audio",

            "volume": 0.9

          "start": 0,
          "length": "auto"
        }
      ]
    }
    ```
  </Step>

## Troubleshooting

### ❌ Problemas Comuns

<AccordionGroup>
  <Accordion title="Sincronização Desalinhada" icon="clock">
    **Problema**: Texto não está sincronizado com a música
    
    **Soluções**:
    ```json
    {
      "clips": [
        {
          "start": 0,     // Início preciso
          "length": 15.5  // Duração exata
        }
      ]
    }
    ```
    
    - Use durações decimais precisas
    - Teste com trechos pequenos primeiro
    - Ajuste baseado no BPM da música
  </Accordion>
  
  <Accordion title="Qualidade de Áudio Baixa" icon="volume-x">
    **Problema**: Áudio com qualidade ruim
    
    **Soluções**:
    ```json
    {
      "asset": {
        "type": "audio",
        "src": "high_quality_audio.mp3",
        "volume": 0.9
      },
      "output": {
        "bitrate": "10000k"
      }
    }
    ```
    
    - Use arquivos de áudio de alta qualidade
    - Aumente o bitrate de saída
    - Evite compressão excessiva
  </Accordion>
  
  <Accordion title="Texto Ilegível" icon="eye-slash">
    **Problema**: Texto não é visível sobre o background
    
    **Soluções**:
    ```json
    {
      "style": {
        "fontSize": 48,
        "fontColor": "white",
        "outlineColor": "black",
        "outline": 4,
        "bold": true
      }
    }
    ```
    
    - Use cores contrastantes
    - Adicione outline grosso
    - Teste em diferentes backgrounds
  </Accordion>
</AccordionGroup>
